# 品牌、视觉与界面设计规范

[English](./design-system.md)

`dislop` 用于检出文稿、演示文稿与前端界面里的模板化水词和结构缺陷，因此项目自身的品牌标识、文档横幅与官方网站（`site/`）采用同一套可核验的设计语言：**建筑网格上的印刷校样单 + 手批圆头记号**（配套品牌人格与表达基准见 [brand-and-voice-guide.zh-CN.md](./brand-and-voice-guide.zh-CN.md)）。其中可机械判定的规则与对比度由 CI 中的 `dislop check . --fail-on warning` 与 `tests/test_site.mjs` 自动检查。

## 1. 视觉定位：同时避开两代 AI 默认模板

当前生成式开发工具页面普遍落入两类高频视觉套路：

1. **第一代模板（2023–2025）**：深蓝黑底配蓝紫粉霓虹渐变、满屏 `rounded-full` 胶囊标签与渐变裁切大标题。
2. **第二代模板（2025–2026）**：当提示词禁止紫色渐变后，模型普遍退回暖米白底（`#F7F5F0`）、Tailwind 暖黑（`#1C1917`）配朱砂橙红——形成新的同质化“暖色人文模板”。

`dislop` 同时避开这两类默认解，参考校对工作本身用的东西：

- **印刷清样（西方 Galley Proof 与国家标准 GB/T 14706《校对符号及其用法》）**：中性棉浆纸白底、高对比碳黑墨迹、待审文稿用衬线体排版，批注置于右侧页边栏并与原文行号对应。
- **工程结构标尺**：使用连续的 `1px` 细实线划分版面分栏，单元格采用 `0–4px` 直角/微圆角，不叠毛玻璃和弥散阴影；首屏直接提供可编辑、可复检的校样工作台，不放空洞宣传画。

## 2. 品牌图形与字标

- **图形标识（`assets/logo.svg`）**：取自中西共通的**删除号（*dele* / GB/T 14706 删除号）**——一笔横线穿过浅色原稿行，向右上方挽出圆环后利落撇出。图形在 `16×16`（浏览器标签页图标）、`64×64`（GitHub 组织头像）与 `512×512` 下均保持环内留白通透、不糊成色块。
- **字标**：全小写无衬线粗体 `dislop`（`letter-spacing: -0.025em`），不挂版本号胶囊、星芒图标或多层套框。桌面端（`>= 1100px`）字标右侧用 `1px` 竖线隔开一行等宽小字 `AI 味检查 · v版本号`，版本号由 `scripts/build_site.mjs` 按 `package.json` 写入，窄屏隐藏。
- **首屏删除号动作**：首屏划掉 `好的，以下是为您润色后的版本。` 的那一笔，就是图标里的删除号：`--pen` 横线穿过整句，在句尾向右上挽出圆环再向右下撇出（`viewBox 0 0 340 40`，`stroke-width: 3`，`vector-effect: non-scaling-stroke`）。只在加载时画一次（`300ms ease-out`），`prefers-reduced-motion` 下直接显示终态；圆环收在句尾的 `40px` 留白里，不压到下方主标题。
- **仓库双主题横幅（`assets/banner-light.svg`、`assets/banner-dark.svg`）**：在 `README` 中通过 `<picture>` 标签自适应 GitHub 浅色与深色模式，双主题图标均保留同一枚朱红笔迹（`#F04438`），右侧标本严格遵循红蓝两套语义：朱红实线仅标出 `core` AI 残留硬伤（`chatbot-artifact`），群青虚线标出套话与模板味提醒。
- **社交预览卡（`assets/og-card.svg`、`assets/og-card.png`，`1200×630`）**：印刷校样风 Open Graph 预览图，构建期同步至 `site/assets/`，适配 X、GitHub、Slack、Discord 与微信链接转发。
- **对外演示动效（`assets/demos/*-{zh,en}-v2.{gif,webp}` 与 `-poster.png`）**：面向 README、官网、`/guides/` 与编辑器市场的分语种渐进式演示图（无损动态 WebP 优先、无抖动 GIF 回退、减动效静态海报），制作规范、编码实测与自动化门禁见 [gif-production-guide.zh-CN.md](./gif-production-guide.zh-CN.md)（[English](./gif-production-guide.md)）。

## 3. 色彩令牌与深色模式单调亮度阶梯

全部文字与背景组合均实测通过 **WCAG 2.2 AA 标准（正文 >= `4.5:1`，大字号 >= `3.0:1`）**，功能性控件边框（`--control-border`）在各相邻表面上均超过 **WCAG 2.2 非文本对比度（`>= 3.0:1`）**。深色模式下，表面明度（`L*`）按“外框画布 -> 正文清样纸 -> 悬浮控件”严格单调递增，杜绝底层比上层卡片更亮的 Z 轴倒置（仅代码/输入框内凹槽 `--inset` 允许更暗）。

|---|---|---|---|---|---|

| `--stage` | 页面外围画布 | `#F6F7F5` | —（`L* = 97.1`） | `#0E1012` | `L* = 4.6` |
| `--sheet` | 主清样栏 / 内容面板 | `#FFFFFF` | —（`L* = 100.0`） | `#15181C` | `L* = 8.1`（高于 `--stage`） |

### 炭黑墨台（`--ink-stage`，浅深色主题通用）

图标底块的 `#14171A` 直接做成三处深色台面：首屏“发给 Agent”提示卡、接入区的代码终端（`#cli-mcp`）和演示区的放映台（`#demos`）。墨台在两种主题下取值不变；深色主题里墨台与清样纸几乎同色，外框改用 `--rule-strong` 描出边界。

| 令牌 | 用途 | 取值 | 在 `#14171A` 上的对比度 |
|---|---|---|---|
| `--ink-stage` | 墨台底色 | `#14171A` | — |
| `--ink-stage-elevated` | 墨台内的标签条 / 页签带 | `#1D2127` | — |
| `--ink-stage-border` | 墨台内 `1px` 分界线 | `#2D333B` | 装饰线 |
| `--ink-stage-control-border` | 墨台内控件边框 | `#6F7784` | `4.0 : 1`（页签带上 `3.6:1`） |
| `--ink-stage-ink` | 墨台正文 | `#ECEEF0` | `15.5 : 1` |
| `--ink-stage-muted` | 墨台次级文字与未选中页签 | `#A6ACB5` | `7.9 : 1` |
| `--ink-stage-pen` | 墨台上的红色小字（时长、徽记） | `#FF7A6B` | `7.1 : 1`（页签带上 `6.4:1`） |
| `--ink-stage-focus` | 墨台内键盘焦点框与链接 | `#85B4FF` | `8.5 : 1` |

`#F04438` 在墨台上只画 `>= 2.5px` 的笔画（删除号、选中页签下沿），小字号红字一律用 `--ink-stage-pen`。

## 4. 红蓝双标线校对语义

任何状态均不只靠颜色区分，而是同时绑定**线型**与**等宽字母标签**：

1. **朱红实线（`--mark-error` + `2px solid` 下划线 + `error`）**：代表 `core` AI 残留硬伤（正文开头的 AI 寒暄、未填占位符、贴进 Word/PPT 没渲染的裸 Markdown、空链接 `<a href="#">` 与无说明禁用按钮）。页面上的红色只有两种：这条硬伤标线，以及品牌笔迹 `--pen` 画出的 `>= 2.5px` 粗笔画（图标、首屏删除号、当前选中项的竖条或下沿、首屏示例进度条、主推价格列顶边）。不用红色填色块、红色徽章或红色装饰字。
2. **群青虚线（`--mark-warn` + `1.5px dashed` 下划线 + `warn` / `info`）**：代表场景包里的套话与模板味提醒（例如开场铺垫、`不是 A，而是 B` 否定反转、连发短句口号、默认紫粉渐变或幻灯片文字墙）。

## 5. 字体栈与中英混排细节

全站零外部字体 CDN 请求（不连 `fonts.googleapis.com` 或 `jsdelivr`），兼顾中国大陆与海外首屏直开速度，并确保浏览器工作台零外发连接。

- **待审文稿衬线栈**：`Georgia, "Source Serif 4", "Noto Serif CJK SC", "Songti SC", "STSong", "Microsoft YaHei", serif`（Windows 下以雅黑兜底避免回退点阵中易宋体；单行宽度控制在英文约 `65ch`、中文约 `36` 字；行高英文 `1.6`、中文 `1.8`）。
- **界面控件与标题无衬线栈**：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- **行号、规则 ID 与命令行等宽栈**：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`，统一开启 `tabular-nums` 等宽数字对齐。

## 6. 网格、控件与平面纪律

- **1px 通栏标尺**：主体最大宽度 `1240px`，左右以连续 `1px` 纵向标尺收束，模块间以通栏水平细线切分，不堆叠三层套盒（`box-in-box-in-box`）。每个章节标题左侧在标尺上留一道 `18px` 长的 `1px` 刻度线，标题本身保持一句人话，不加编号眉题。
- **三层控件**：主操作 `.btn-primary`（墨色实底、`6px` 圆角）每屏只放一到两个；常规控件 `.ctrl-btn`（`--raised` 底 + `--control-border`）；安静控件 `.sheet-btn`（透明底 + `--control-border-quiet`，悬停描 `--ink`）用在工作台工具条的次要动作、规则筛选、案例分享和演示控制，避免整排灰色按钮一样重。
- **清样三栏自适应（桌面端三栏，`< 1040px` 批注落至底部，`< 820px` 移动端单栏流式折叠）**：左侧为标本目录，中间为带行号槽的可编辑原稿纸，右侧为判断方法与改稿对照；小屏下保证 `375px` 宽度零横向溢出。
- **演示放映台**：`#demos` 的六段动画默认是两列网格（没有脚本时也能全部看到）；脚本加载后改成墨台上的单场景放映：顶部一排页签（`role="tablist"`，支持方向键），左侧 `1.35fr` 画面，右侧 `0.65fr` 说明与定格 / 重播 / 放大控件。
- **社交标本卡与宣发短片（墨台托清样 / Slip on Ink Stage）**：对外社交配图（`1600×900` 横图、`1200×630` Open Graph、`1242×1660` 竖版图文）与宣发短片统一以满版炭黑墨台 `--ink-stage`（`#14171A`）托起中间 `0px` 直角的白纸清样 `--sheet`（`#FFFFFF`），避免纯白卡片在浅色信息流里漏边消失。信息流标本字号放大到缩略态可读（`1600×900` 正文 `>= 28px`，`1242×1660` 竖图正文 `>= 42px`），删除号圆环与红实线 / 蓝虚线均按浏览器实测字符宽度（`getBBox()`）精确定位，通过态只用 `--mark-ok`（浅底 `#1E6B47` / 深底 `#6CD49B`），构造示例统一在右上角挂等宽 `构造示例` / `EXAMPLE` 标签。
- **零死点击控件与三层圆角**：贴合标尺的单元格保持 `0px` 直角；可按按钮采用 `--radius-ctrl: 6px`（小按钮 `5px`），呼应图标底座的温和圆角；内凹输入框与代码槽用 `--radius-input: 4px`。常规过渡不超过 `120ms`（仅笔迹检查动效允许一次 `240–300ms` `ease-out`），且遵循系统 `prefers-reduced-motion` 设置。中文标题设 `letter-spacing: 0`。
