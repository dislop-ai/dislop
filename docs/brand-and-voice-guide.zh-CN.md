# 文案、表达与视觉基准

[English](./brand-and-voice-guide.md) · [产品定义（Product Brief）](../PRODUCT.md)

写 `dislop` 的文档、官网、CLI 提示或发布说明时，只有一个总要求：**像做这个工具的人在平时说话一样写，朴实、轻松、直接。** 对外 Slogan（`去 AI 味才是真正的生产力！` / `Cutting AI slop is real productivity.`）、定位、目标用户、卖点与标准一句话介绍一律以 [PRODUCT.md](../PRODUCT.md) 为准。

不用四平八稳，不用讨好谁，也不用刻意显得“专业”“克制”或“有文采”。

---

## 1. 一次真实复盘：0 命中为什么还是满屏 AI 味

我们上一版官网首屏自己跑 `dislop check --fail-on info` 是 `0 findings`，但摆在浏览器里一眼就能看出是 AI 写的：

```text
旧版（0 findings，但明显有 AI 味）：
你的稿子，不带 AI 味。
把稿子、PPT 或网页贴进来。不能发的硬伤，dislop 直接划掉；听着像套话的地方，它在页边问你一句；等你改完，再拿原稿逐条对一遍数字、链接和引用。它不替你改稿，笔一直在你手里。
```

问题不在某个禁用词，而在四种常见的 AI 写作习惯：

- **三段对称分号推销句**（“不能发的……；听着像套话的……；等你改完……”），试图用工整排比一次塞完三个卖点，读起来像广告稿。
- **段尾金句收尾**（“它不替你改稿，笔一直在你手里。”），像专门写来让人截图发朋友圈的引用卡片。
- **老派校对编辑戏服**（“在页边问你一句”“蓝笔商榷”“可以付印”“同路清单”），不像普通人平时说话。
- **逗号劈开的口号标题**（“你的稿子，不带 AI 味。”“不能发的，直接划掉。”），自带投放海报味。

把这四层演出来的东西全剥掉，直接说工具到底干什么：

```text
新版（朴实、直接）：
把稿子里的 AI 味挑出来
AI 写完的文档、PPT 或网页，经常夹着开头寒暄、空话套话、满页字墙或默认紫粉渐变。dislop 负责在本地把这些问题标出来，方便你或你的 Agent 对照修改；在网页工作台或远程 MCP 里也可以按需切换云增强改写。
```

不玩比喻，不甩金句，不把三个功能绑在分号里排排坐。读者三秒就能看懂它是干什么的。

## 2. 我们的写法：大部分写成朴实短句，保留平时说话的松弛感

我们参考 **ASD-STE100**（简化技术英语）的朴实原则，把大部分句子写成直白短句，同时保留人写文档时的松弛感。结合 `stop-slop` 社区总结的结构性去味经验，我们定六条可直接执行的规矩：

1. **一句只讲一件事，长短自然错开。** 写完如果出现两个以上分号拼起来的工整长句，直接拆开。
2. **同一个东西一直叫同一个普通名字。** 不要为了显得有变化，把 `warning` 一会儿叫“蓝笔商榷”、一会儿叫“语境提示”。全站统一叫普通词：中文用 `硬伤`、`提醒`、`通过`、`没通过`、`工具清单`；英文用 `hard bug`、`warning`、`passed`、`rejected`、`Awesome list`。
3. **去掉所有“金句收尾”和戏服比喻。** 读起来像海报标语、引用卡片或角色扮演的句子（例如“笔一直在你手里”“可以付印”“底盘如机印般沉稳”），直接删掉或改回大白话。
4. **先写具体对象，再讲道理。** 第一句尽量落在一段原文、一个文件、一条命令或一个真实问题上，少写“在当今……背景下”式的铺垫。
5. **能查的和查不了的都直说。** 损坏读不出来的压缩包、还没上线的功能（如代码 AST 检查）直接写“跳过”或“还没做”，不含糊带过。
6. **中英文各做各的原生表达，严格不混排。** `dislop.com` 和 `/awesome/` 根据访问者浏览器语言自动默认中文或英文（不写死单一语种），保留一键切换。中英文物料不是逐字翻译关系，而是各自面向对应世界独立制作文案、例句、头图与社交帖（如 X 可发一条独立中文，再发一条独立英文）。中文页只放中文例子和说明，英文页只放英文例子和说明。内部研究词（`Level 0`、`L0–L3`、`Stage-3`、`负向防线`、`正向牵引`、`三带熵`、`人机双读`）只留在 `docs/research/`。

### 常见界面文案对照

| 场景 | 别这么写（AI 腔 / 角色扮演） | 直接这么写（中文） | 直接这么写（英文） |
|---|---|---|---|
| **主标题 / Slogan** | `你的稿子，不带 AI 味。` | `去 AI 味才是真正的生产力！` | `Cutting AI slop is real productivity.` |
| **说明段落** | `不能发的硬伤直接划掉；听着像套话的问你一句……笔一直在你手里。` | `dislop 负责在本地把问题标出来，方便你或 Agent 对照改掉；需要时也能在工作台切到云增强改写。` | `dislop marks what looks off locally so you or your agent can fix it, with optional Cloud MCP rewrites.` |
| **检查干净** | `可以付印。0 处标记，受保护事实完好保留。` | `0 处问题。寒暄和空话都清掉了。` | `0 issues. Chat wrapper and stock phrasing removed.` |
| **换了种 AI 味** | `退回重对：二阶位移拦截` | `依然标出 1 处。旧套话删掉了，但换成了“不是……而是……”这种二阶 AI 腔。` | `Still flagged (1 issue). Old buzzwords are gone, replaced by a 'Not X, but Y' AI slogan.` |
| **目录名** | `同路清单` | `工具清单` / `去 AI 味工具清单` | `Awesome list` / `Awesome Anti-Slop` |
| **隐私说明** | `100% 物理锁死外发请求` | `只在当前浏览器标签页里跑，不上传文件。` | `Runs only in this browser tab. Nothing gets uploaded.` |

### 诚实边界

- **只查 AI 味，不冒充全能 QA**：`dislop` 不做通用安全路径扫描、PDF 预检或 WCAG 对比度审计。
- **不说假 0 问题**：空稿、损坏的 Office 文件或隐藏幻灯片各自如实显示，不混成“0 处问题”。

## 3. 视觉与 UI：俏皮留在图标和笔画里，版面保持干净克制

文字退回朴实，不等于页面要变得死板。我们把一点轻快和温度留在视觉记号里，灵感来自 [assets/logo.svg](../assets/logo.svg)。深炭黑圆角底（`#14171A`）上留着浅灰原稿线，朱红圆头笔画（`#F04438`）把多余的部分轻轻圈出去，剩下的原样不动。首屏那道划掉 `好的，以下是为您润色后的版本。` 的红线，就是把图标做成实际动作，不需要再配文案解释“我是你的红笔编辑”。

完整色值和对比度实测见 [design-system.zh-CN.md](./design-system.zh-CN.md)。页面保持 `1px` 细线网格、冷中性纸面（`#F6F7F5` / `#FFFFFF`）、深色模式严格递增明度（`#0E1012 → #15181C → #1D2127`），不加载第三方字体，不发外域请求（`CSP: connect-src 'self'`，离线检查默认零上传），也不用紫粉霓虹渐变或暖米白陶土模板。

图标与粗笔画统一用 `--pen`（`#F04438`，浅深色不变）；浅色小号红字用 `#B42318`（`6.6:1`），深色用 `#FF7A6B`（`7.0:1`），深色模式下给图标底块加 `1px` 细边，避免融进顶栏。网格单元保持 `0px` 直角，按钮用 `6px`（小按钮 `5px`），输入框用 `4px`，不堆 `999px` 胶囊标签；等宽字体只用于代码、行号、规则 ID 和统计数字，中文标题设 `letter-spacing: 0`。

两种标线不靠颜色也能分清：

- 红实线（`2px solid`）：AI 残留硬伤（`error`）
- 蓝虚线（`1.5px dashed`）：套话与模板味提醒（`warning` / `info`）

## 4. 发之前过一遍（7 个检查问题）

改官网、README、CLI 提示或分享文案前，顺手问自己这七句：

1. 读出声来，像平时跟同事聊天，还是像 AI 写的宣发稿？
2. 有没有用分号把三个卖点工整并排塞进一句话？有就拆掉。
3. 段尾有没有一句像“金句卡片”一样的总结句？有就删掉。
4. 有没有给工具穿角色扮演戏服（比如“页边问你一句”“可以付印”）？有就换回大白话。
5. 同一个概念（硬伤 / 提醒 / 通过）在整页里是不是都叫同一个名字？
6. 中英文是不是完全分开，中文页没夹英文例句，英文页没夹中文说明？
7. 跑 `dislop check <file> --fail-on info` 是不是 0 命中；正文不堆 `!`、表情符号和 `finding(s)`（仅官方中文 Slogan `去 AI 味才是真正的生产力！` 保留原话 `！`）。

机读参考配置见 [docs/brand/voice.json](./brand/voice.json)（`dislop.voice/1` 草案）。
