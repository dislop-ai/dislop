    接入方式：纯文档 Skill、本地 CLI 与云端 MCP

    按你手上的工具选一种，每种都有能直接复制的配置。

    1. 纯文档 Agent Skill

      按文体整理的写作与界面避坑卡，不带脚本。装进 Claude Code、Codex、Cursor 或 Antigravity，Agent 动笔前读取，写完再调用本地 CLI 自检。

    2. 开源本地 CLI 与插件

      Node.js 20+ 零外部依赖微内核，内置 11 套模块化规则包，支持 .dislop.json 分目录覆盖与 .dislop/rules.json 自定义规则。断网也能查文档、Word、PPT、PDF 和 Git 改动，还可选 Ollama 本地小模型或自有密钥。

    3. 官方云端 MCP 与网页工作台

      在 WorkBuddy、千问、Claude Cowork 或编辑器里直连，登录后每月 30 免费额度，按文体做多模型审校并返回改法。

      https://dislop.com/mcp

    4. 一句话让 Agent 自己接管

      把 dislop.com/llms.txt 发给你的 Agent，它会自己判断装 Skill、CLI 还是远程 MCP，再拿现有文件试跑一次。
