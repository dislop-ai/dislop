内置去 AI 味规则明细

7 套场景包一共内置 53 条规则，CLI、插件和浏览器工作台都离线自带。点开任意一条都能看判断方法、正反句对照和命令行用法。

交付底线 core

所有规则包默认开启的明显 AI 残留硬伤：留在正文里的 AI 寒暄、未填占位符、贴进 Word/PPT 没渲染的裸 Markdown，以及 AI 网页里的空链接与假按钮。

规则级别格式查什么
忘了填的占位符
unfilled-placeholder
 硬伤 markdown, text, html, jsx, svg, docx, pptx, pdf 存在未替换的模板占位符或测试假文。
留在正文里的 AI 寒暄
chatbot-artifact
 硬伤 markdown, text, html, jsx, docx, pptx, pdf 残留未清理的 AI 对话寒暄壳或检索引用内部标记。
没渲染的 Markdown 符号
markdown-leak
 硬伤 docx, pptx, pdf Word 或 PowerPoint 文本中残留未渲染的原始 Markdown 标记（如 **加粗** 或 ## 标题）。
点不动的假按钮或空链接
ui-dead-control
 硬伤 html, jsx AI 生成网页常见的空跳转链接（href="#"）、空按钮或未说明原因的占位禁用按钮。

工作文档 business-brief

检出铺垫废话、空洞套话、二阶对比口号（“不是 A，而是 B”）、断句口号链、四字排比串与无出处归因。

规则级别格式查什么
英文铺垫开场白
en-throat-clearing-opener
 提醒 markdown, text, html, docx, pptx 英文铺垫式开场白拖延了核心事实。
英文高频套词
en-cliche-lexicon
 轻提示 markdown, text, html, docx, pptx 高频公关套语，建议替换为具体动作或实测指标。
公文黑话与空泛词
zh-bureaucratic-padding
 提醒 markdown, text, html, docx, pptx 存在空泛汇报套词或铺垫口头禅，掩盖了具体动作、主体与结果。
“不是 A，而是 B”套句
negation-pivot-frame
 提醒 markdown, text, html, docx, pptx 二阶“不是 A，而是 B”对比修辞：先否定稻草人再拔高抽象概念，缺乏具体事实增量。
英文短句口号连发
staccato-slogan-run
 提醒 markdown, text, html, docx, pptx 连续三个及以上超短断句口号（第二代 AI 戏剧化腔调）。
四字排比串
zh-four-char-triad
 提醒 markdown, text, html, docx, pptx 连续三个及以上四字套语并列（如“精准高效、安全可靠、灵活易用”），信息密度低。
没写明出处的“研究表明”
unsourced-attribution
 提醒 markdown, text, html, docx, pptx 出现“研究表明/数据显示/业内人士指出”等模糊权威背书，但句内无具体机构、年份、链接或引用标记。
满屏“加粗词 + 冒号”清单
bold-lead-list-wall
 轻提示 markdown, text 连续 4 条及以上 - **小标题**：说明 列表墙，呈现典型大模型平铺罗列感。
低事实段落堆叠空泛动词
cooccurrence-slop-cluster
 提醒 markdown, text, html, docx, pptx 同一低事实段落内密集堆叠多个弱套词组合（如“有效推动/持续优化/显著提升”或“leverage/streamline/robust”），冲淡了具体改动。
三段对称分号推销句
semicolon-tricolon
 提醒 markdown, text, html, docx, pptx 单句内连续使用两个及以上分号构成三段对称排比，呈现典型 AI 推销腔。
自问自答式营销设问
rhetorical-qa-cadence
 提醒 markdown, text, html, docx, pptx 自问自答式设问套路（“为什么……？因为……”“结果呢？”），带有明显生成式营销文节奏。
五连逗号一逗到底长句
comma-chain-runon
 轻提示 markdown, text, html, docx 单句内连续串接 5 个及以上逗号分句，节奏平铺拖沓。
趋势帽开场与展望帽收尾
narrative-sandwich-frame
 提醒 markdown, text, html, docx 出现宏大趋势开场（“随着……的飞速发展”）、展望式升华收尾（“展望未来……”）或连接词堆叠（“此外/与此同时/不仅如此”），呈现典型 AI 三明治叙事壳。
连续三段同构句首填表腔
template-skeleton-echo
 提醒 markdown, text, html, docx 连续 3 个及以上段落或句子复用同一句首骨架（如“在……方面，”“首先/其次/再次/最后”“By …ing,”），结构像套模板填词。
句长齐平且缺具体事实
low-burstiness-vapor
 轻提示 markdown, text 多句段落同时出现句长高度齐平（突发性变异系数 CV < 0.24）且几乎没有具体锚点（数字、时间、文件名或可核查动作），空泛同质感强。
中文研发与产品自嗨黑话
zh-dev-jargon
 提醒 markdown, text, html, docx, pptx 单段集中出现 AI 爱写的空洞自嗨黑话（如“全闭环/深度赋能/范式跃迁/零失误/体系化”），而非具体工程或业务机制；偶发行业实词会自动豁免。
中文正文鸡血感叹号
zh-exclamation
 提醒 markdown, text, html, docx, pptx 中文正文段出现鸡血营销感叹号（2 处及以上或搭配“太棒了/重磅/彻底告别/震撼”等煽动词），破坏冷静客观的叙述语气。
中文超长一逗到底单句
zh-mega-sentence
 提醒 markdown, text, html, docx 中文单句一逗到底超过 180 个汉字（或 >= 120 汉字且总长超 180 字），阅读负担重，呈大模型长从句生成特征。
无基线/出处的百分比宣称
unsourced-statistic
 提醒 markdown, text, html, docx, pptx 宣传式百分比数字宣称（如“提升 40%”“高达 80%”“up to 50%”）附近缺少测试基线、样本数、指标口径或引用来源。

研发文档与复盘 engineering-spec

在技术文档与简报检查之上，专门拦截空洞的 AI 代码提交总结、把事故归结为“人为失误”的止步归因，以及无负责人无指标的许愿式改进项。

规则级别格式查什么
空泛的 AI 提交摘要壳
eng-pr-diff-parrot
 提醒 markdown, text 空泛的 AI 提交摘要只重复“通过优化提升可维护性”，未说明具体修掉的缺陷、边界条件或单号。
复盘止步于“人为失误”
eng-shallow-root-cause
 提醒 markdown, text, docx 故障复盘停在“人为失误/操作不当”，没有追查缺失的系统校验或防呆机制。
无指标无负责人的改进项
eng-vague-action-item
 轻提示 markdown, text, docx 许愿式改进项（如“加强监控”“提高警惕”）缺少具体模块、阈值、负责人或截止时间，无法验收。

对外合规 regulated-comms

面向对外公告、客户方案与合规审校，拦截绝对化极限承诺（“零风险”“绝对安全”“行业第一”）及无基线倍增夸大（“效率提升数倍”）。

规则级别格式查什么
绝对化承诺与极限合规词
reg-unsubstantiated-superlative
 提醒 markdown, text, html, docx, pptx 出现绝对化承诺或极限排他用语（如“绝对安全”“零风险保障”“全网第一”），存在合规与履约风险。
无基线的悬空倍数宣称
reg-unanchored-multiplier
 提醒 markdown, text, html, docx, pptx 出现悬空的倍数宣称（如“10x faster”“效率提升数倍”），句内未给出改动前后的具体基线数值。

随笔长文 literary-essay

克制段尾升华说教、二阶对比金句、破折号过密与中文半角标点混排，保留具体细节与自然语感。

规则级别格式查什么
段尾说教式升华
zh-essay-moralizing-ending
 提醒 markdown, text, html, docx 段尾出现说教升华套句，冲淡了前文的具体细节。
英文段尾升华
en-essay-moralizing-ending
 提醒 markdown, text, html, docx 英文感伤升华结语直接替读者总结情绪，削弱了叙事余味。
金句腔“不是……而是……”
literary-negation-pivot
 提醒 markdown, text, html, docx 套路化“不是 A，而是 B”金句打断叙事质感。
破折号太密
excessive-em-dash-density
 轻提示 markdown, text, html, docx 破折号（— / ——）密度过高，形成典型生成式插话腔。
中文里混了半角标点
zh-halfwidth-punctuation
 提醒 markdown, text, html, docx 汉字之间混入半角西文标点（,;:!?），违反中文排版规范（W3C CLREQ）。
散文三段分号排比腔
literary-semicolon-tricolon
 提醒 markdown, text, html, docx 单句连续用两个及以上分号排比景物或情绪，带有明显的生成式散文腔。
随笔自问自答抒情腔
literary-rhetorical-qa
 提醒 markdown, text, html, docx 散文里出现自问自答式设问（“为什么……？因为……”），像主持词而非真实叙述。
随笔时代大帽子与升华尾
literary-narrative-frame
 提醒 markdown, text, html, docx 以宏大时代背景起笔（“在快节奏的都市生活中……”）或未来式鸡汤收尾，给随笔套上了模板外壳。

PPT 和网页 deck-and-ui

检查 PPT 与横版 PDF 文字墙、自动缩排、空泛标题，以及网页里的紫粉渐变、霓虹光球、Emoji 图标堆砌、模板卡格、SVG 排版缺陷和图片工作流残留与塑料配色。

规则级别格式查什么
单页 PPT 字太多
slide-word-wall
 提醒 pptx, pdf 单页幻灯片可见文字超载（英文 > 120 词或中文 > 280 字），变成文档搬家。
单页要点超过 6 条
slide-bullet-overload
 提醒 pptx 单页幻灯片项目符号超过 6 条（maxSlideBullets），视觉层级碎裂。
PPT 文字被硬缩太小
slide-autofit-shrink
 提醒 pptx 文本框触发 PowerPoint 自动缩排（fontScale < 80%），表明文案超出容器容量。
幻灯片标题太泛
slide-weak-topic-title
 轻提示 pptx 正文密集的幻灯片使用“背景/概述/总结”等空泛名词做标题，未直接亮出本页结论。
默认紫粉霓虹渐变
ui-ai-gradient
 提醒 html, css, jsx, svg, pdf 使用默认紫粉/蓝紫高饱和渐变或渐变裁切艺术字标题（典型生成式模板特征）。
满屏胶囊小标签
ui-pill-soup
 提醒 html, jsx 单视图堆砌超过 6 个胶囊圆角文字标签（rounded-full / 999px），导致视觉噪音泛滥。
框套框套框（三层套盒）
ui-box-in-box
 提醒 html, jsx 连续三层及以上带边框与圆角的容器层层套盒，挤压有效内容空间。
把提示词印成了界面徽章
ui-prompt-echo-badge
 提醒 html, jsx, svg 界面标签直接回显提示词营销口号（如AI 强力驱动零幻觉保证），未说明具体功能。
霓虹光晕球与闪烁圆点
ui-glow-blob-chrome
 提醒 html, css, jsx, svg 堆砌装饰性环境光晕球（blur-3xl）、霓虹色阴影、闪烁 animate-ping 小圆点或重度 SVG 发光滤镜。
界面标题堆砌通用 Emoji
ui-emoji-icon-chrome
 提醒 html, jsx, svg 在界面标题、按钮或卡片里堆砌 3 处及以上通用 Emoji（如 🚀、✨、⚡、🛡️）充当图标。
彩色图标方块与假窗口三点
ui-template-card-grid
 提醒 html, jsx 命中生成式界面三大件：彩色圆角方块图标卡（>= 3 组）、假 macOS 三色窗口圆点或 01/02/03 编号眉题。
SVG 缺 viewBox 或文字重叠
svg-layout-slop
 提醒 svg SVG 平面图形存在生成式结构缺陷：大画布缺失 viewBox、文字坐标重叠或 <defs> 中残留 2 处及以上孤立未用定义。
图片残留生成参数或来源标识
image-ai-workflow-residue
 提醒 image 图片文件内嵌了未清理的生成提示词/工作流参数（提醒），或带有显式 AI 生成来源标识（提示：合规场景请保留法定标识，重点复核成图质感）。
PNG 霓虹紫粉或高饱和塑料质感
image-ai-palette-slop
 轻提示 image PNG 像素分布呈现典型生成式视觉套路：高占比蓝紫霓虹主色，或大面积高饱和光滑“塑料感”涂抹。
PDF 纯图幻灯片或字阶扁平
pdf-visual-layout-slop
 提醒 pdf PDF 演示页或海报存在排版缺陷：多页全图无可选文字、横版页字阶扁平或正文缩至 < 9.5pt，或连续 4 页及以上同骨架纯字横版页。

管理汇报 executive-deck

在演示文稿与界面规范之上，检查非结论式“过程名词”幻灯片标题与连续同骨架纯文字页。

规则级别格式查什么
汇报标题只写“关于……的分析”
slide-process-not-finding-title
 提醒 markdown, pptx 标题只写了“关于……的分析/汇报”这类过程标签，没有直接亮出本页结论。
连续 4 页纯文字同版式 PPT
pptx-layout-monotony
 轻提示 pptx 连续 4 页及以上幻灯片重复完全相同的纯文字要点骨架（无表格、图表或版式变化），容易引发审阅疲劳。
