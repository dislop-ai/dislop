没渲染的 Markdown 符号

markdown-leak 交付底线 (core) 硬伤 docx, pptx, pdf Markdown 规则卡
判断方法

去掉原始星号或井号，改用 Word/PowerPoint 原生样式或加粗格式。

这条规则查什么

Word 或 PowerPoint 文本中残留未渲染的原始 Markdown 标记（如 **加粗** 或 ## 标题）。
