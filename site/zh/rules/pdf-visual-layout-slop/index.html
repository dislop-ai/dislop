PDF 纯图幻灯片或字阶扁平

pdf-visual-layout-slop PPT 和网页 (deck-and-ui) 提醒 pdf Markdown 规则卡
判断方法

导出可选择矢量文本而非整页贴图，拉开至少 1.2 倍的标题与正文字号阶梯（正文 >= 11pt），并穿插表格或图表。

这条规则查什么

PDF 演示页或海报存在排版缺陷：多页全图无可选文字、横版页字阶扁平或正文缩至 < 9.5pt，或连续 4 页及以上同骨架纯字横版页。

原句与改法对照

原句（会标出问题）
连续多页横版 PDF 全是整页位图，或把正文缩到 8.5pt 挤满纯字页面。
改干净的版本
保留可选矢量文字，保持 1.2 倍以上标题正文字号阶梯并穿插图表。

改法要点： 竖版长文报告与单页作品集豁免横版幻灯片单调与文字墙检查。

命令行单独查看或检查

npx --yes dislop explain pdf-visual-layout-slop
npx --yes dislop check . --pack deck-and-ui
