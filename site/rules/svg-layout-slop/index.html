dislop / 规则百科 / svg-layout-slop

SVG 缺 viewBox 或文字重叠

svg-layout-slop PPT 和网页 (deck-and-ui) warning svg Markdown card
判断方法

补齐显式 viewBox，拉开重叠文字坐标，并清理 <defs> 里未被引用的冗余渐变与滤镜。

这条规则查什么

SVG 平面图形存在生成式结构缺陷：大画布缺失 viewBox、文字坐标重叠或 <defs> 中残留 2 处及以上孤立未用定义。

原句与改法对照

原句（会标出问题）
<svg width="640" height="360"><text x="40" y="50">步骤一</text><text x="42" y="52">重叠字</text></svg>
改干净的版本
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 360" width="640" height="360"><text x="40" y="50">步骤一</text><text x="40" y="96">步骤二</text></svg>

改法要点： 非小图标画布应声明 viewBox、保证文字坐标不碰撞，并删去未被引用的 <defs>。

命令行单独查看或检查

npx --yes dislop explain svg-layout-slop
npx --yes dislop check . --pack deck-and-ui
