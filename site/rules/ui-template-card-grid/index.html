彩色图标方块与假窗口三点

ui-template-card-grid PPT 和网页 (deck-and-ui) warning html, jsx Markdown card
判断方法

删去假窗口圆点、编号眉题和马卡龙图标块，靠真实小标题和对齐建立网格秩序。

这条规则查什么

命中生成式界面三大件：彩色圆角方块图标卡（>= 3 组）、假 macOS 三色窗口圆点或 01/02/03 编号眉题。
