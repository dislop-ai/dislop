Stock AI buzzword

en-cliche-lexicon Business Brief & Technical Proposal (business-brief) info markdown, text, html, docx, pptx Markdown card
How to judge

If you delete this modifier, which concrete mechanism, metric, or trade-off disappears? State that fact directly.

What this rule catches

Stock promotional phrase where a specific verb or measurement would carry more weight.

Before and after examples

Original (flagged)
Batch indexing is a game-changer that unlocks the full potential of our 40-million-row log archive.
Still sounds like AI
This isn't indexing. It's instant recall across 40 million rows.
Clean version
Batch indexing cuts 40-million-row log queries from 19 seconds to 1.4 seconds.

Edit note: Replace hype nouns with before/after query latency while keeping '40-million-row'.

Run locally via CLI

npx --yes dislop explain en-cliche-lexicon
npx --yes dislop check . --pack business-brief
