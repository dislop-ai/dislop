Decorative emoji UI chrome

ui-emoji-icon-chrome Slide Deck, Web UI & Graphic Layout (deck-and-ui) warning html, jsx, svg Markdown card
How to judge

Strip decorative emojis from headings and controls; use plain typography or a consistent single-stroke SVG icon set.

What this rule catches

Three or more decorative AI stock emojis (🚀, ✨, ⚡, 🛡️) used as interface or heading icons.
