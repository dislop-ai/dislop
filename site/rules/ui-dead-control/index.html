dislop / 规则百科 / ui-dead-control

点不动的假按钮或空链接

ui-dead-control 交付底线 (core) error html, jsx Markdown card
判断方法

接上真实链接或交互，或者说明禁用原因；没做的功能直接删掉按钮。

这条规则查什么

AI 生成网页常见的空跳转链接（href="#"）、空按钮或未说明原因的占位禁用按钮。

原句与改法对照

原句（会标出问题）
<a href="#" class="btn">下载完整报告</a>
改干净的版本
<a href="./report.html" class="btn">下载完整报告</a>

改法要点： 链接指向真实地址，不要摆放点不动的假按钮。

命令行单独查看或检查

npx --yes dislop explain ui-dead-control
npx --yes dislop check . --pack core
