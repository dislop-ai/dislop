English and cross-language rules

46 deterministic rules ship inside the offline CLI and browser workbench across 7 scenario packs, each with a check question and before / still-AI / clean examples.

AI Delivery Artifacts core

Clear AI-generation artifacts enabled across every pack: stray chatbot greetings, unfilled placeholders, raw Markdown pasted into Word/PowerPoint, and dead placeholder links/buttons in generated UI.

RuleLevelFormatsWhat it catches
Unfilled placeholder
unfilled-placeholder
 hard bug markdown, text, html, jsx, svg, docx, pptx, pdf Unfilled AI template placeholder or dummy copy.
Chatbot greeting
chatbot-artifact
 hard bug markdown, text, html, jsx, docx, pptx, pdf Unstripped chatbot wrapper sentence or AI search citation token.
Raw Markdown in Office doc
markdown-leak
 hard bug docx, pptx, pdf Raw Markdown syntax (**bold** or ## heading) pasted unrendered into Word or PowerPoint.
Dead placeholder link or button
ui-dead-control
 hard bug html, jsx Placeholder href="#" link, empty button, or unexplained disabled button typical of generated UI mockups.

Default purple-pink AI gradient

Pill-badge soup

Three-level nested boxes
ui-box-in-box
 warning html, jsx Three or more nested bordered/rounded containers wrap the same content (box-in-box-in-box).
Prompt-echo marketing badge
ui-prompt-echo-badge
 warning html, jsx, svg Interface chrome echoes prompt-engineering hype (AI-Powered, Zero Hallucination) instead of naming the function.
Ambient glow orbs & pulsing dots
