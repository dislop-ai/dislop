Multiplier claim without baseline

reg-unanchored-multiplier External & Regulated Communications (regulated-comms) warning markdown, text, html, docx, pptx Markdown card
HOW TO JUDGE

Either add the exact baseline ('from 18s to 1.8s on 10M rows') or remove the multiplier.

What this rule catches

Floating speedup or efficiency multiplier ('10x faster') omits the before/after baseline.

Before and after examples

Original (flagged)
Streaming batch export makes monthly statements 10x faster.
Fallback trap (still sounds like AI)
Streaming batch export transforms monthly statements at lightning speed.
Clean version
Streaming batch export writes rows directly without buffering the full table in memory.

Edit note: When no before/after timing baseline is in the source, state the concrete mechanism and drop the unanchored multiplier.
