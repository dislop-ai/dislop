Default purple-pink AI gradient

ui-ai-gradient Slide Deck, Web UI & Graphic Layout (deck-and-ui) warning html, css, jsx, svg, pdf Markdown card
HOW TO JUDGE

Replace decorative neon gradients with solid surface tokens, crisp 1px rules, and typographic contrast.

What this rule catches

Default purple/indigo-to-pink generator gradient or gradient-clipped display headline.

Before and after examples

Original (flagged)

Fallback trap (still sounds like AI)
<h1 class="bg-gradient-to-r from-teal-400 to-cyan-500 bg-clip-text text-transparent">Release Notes v2.4</h1>
Clean version
<h1 class="page-title">Release Notes v2.4</h1>

Edit note: Swapping purple-pink for teal-cyan gradient text repeats the same template habit; set headlines in solid high-contrast ink.
