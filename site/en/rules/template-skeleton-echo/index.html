Repeated paragraph-opener skeleton

template-skeleton-echo Business Brief & Technical Proposal (business-brief) warning markdown, text, html, docx Markdown card
HOW TO JUDGE

Merge related points into natural prose with varied openings, or use a compact table if you are listing parallel specs.

What this rule catches

Three or more paragraphs or sentences repeat the exact same syntactic opener skeleton ('By <verb>ing...', 'First/Second/Third/Finally').

Before and after examples

Original (flagged)
By standardizing log schemas, teams query events faster.

By automating nightly compaction, storage stays predictable.

By surfacing error budgets, on-call engineers spot regressions early.
Fallback trap (still sounds like AI)
Standardize logs. Compact nightly. Surface budgets.
Clean version
Standardized log schemas speed up ad-hoc queries, nightly compaction caps disk growth, and error-budget alerts catch regressions early.

Edit note: Structural opener shingling catches templated repetition even when every surface noun changes.

npx --yes dislop explain template-skeleton-echo
