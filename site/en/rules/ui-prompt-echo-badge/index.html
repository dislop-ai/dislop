ui-prompt-echo-badge Slide Deck, Web UI & Graphic Layout (deck-and-ui) warning html, jsx, svg Markdown card
HOW TO JUDGE

Delete the AI-Powered badge; label the control by the exact task it performs ('Extract invoice totals', 'Check slide word count').

What this rule catches

Interface chrome echoes prompt-engineering hype (AI-Powered, Zero Hallucination) instead of naming the function.
