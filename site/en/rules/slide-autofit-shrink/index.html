Slide text auto-shrunk too small

slide-autofit-shrink Slide Deck, Web UI & Graphic Layout (deck-and-ui) warning pptx Markdown card
HOW TO JUDGE

Trim the overflowing copy or enlarge the text frame so body type renders at 100% scale.

What this rule catches

PowerPoint normAutofit shrank text below 80% (fontScale < 80000) because copy overflowed its box.

Before and after examples

Original (flagged)
<a:normAutofit fontScale="62500" lnSpcReduction="20000"/> on body placeholder
Fallback trap (still sounds like AI)
Manually hardcode 10pt font so `normAutofit` disappears while text stays illegible.
Clean version
<a:noAutofit/> with 42 words set at 18pt and full line spacing

Edit note: Autofit below 80% is deterministic proof that text did not fit its layout frame.

Run locally via CLI

npx --yes dislop explain slide-autofit-shrink
npx --yes dislop check . --pack deck-and-ui
