dislop / Rules / pptx-layout-monotony

4+ consecutive identical bullet slides

pptx-layout-monotony Executive Slide Deck & Board Readout (executive-deck) info pptx Markdown card
HOW TO JUDGE

Convert comparative bullet slides into a structured table, timeline, or metric chart to break monotonous pacing.

What this rule catches

Four or more consecutive slides repeat the exact same plain text-box skeleton without tables, charts, or visual variation.

Before and after examples

Original (flagged)
Slides 2–5 all use identical 'Title + 4 plain bullets' boxes with zero tables, charts, or diagrams.
Fallback trap (still sounds like AI)
Slides 2–5 keep the exact same 4 bullets per slide and add decorative stock icons.
Clean version
Slide 3 presents regional latency in a 4-row table and Slide 4 plots weekly error budget burn.

Edit note: Match slide structure to the data type instead of pouring every page into the same bullet template.
