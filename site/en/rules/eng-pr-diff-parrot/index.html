HOW TO JUDGE

Replace the wrapper sentence with why the change was needed, what breaks without it, and how it was verified.

What this rule catches

Generic AI PR summary parrots file changes without stating the concrete bug, constraint, or metric.

Before and after examples

Original (flagged)
This PR updates the retry middleware to ensure a more seamless and resilient developer experience
Fallback trap (still sounds like AI)
This isn't a minor retry tweak — it's rock-solid resilience.
Clean version
Fixes #412: cap exponential backoff at 8s when upstream returns HTTP 503.

Edit note: Name the concrete leak trigger and consequence instead of generic stability claims.
