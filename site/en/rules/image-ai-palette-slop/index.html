dislop / Rules / image-ai-palette-slop

PNG neon purple palette or plastic sheen

image-ai-palette-slop Slide Deck, Web UI & Graphic Layout (deck-and-ui) info image Markdown card
HOW TO JUDGE

Review the rendered image for plastic skin/surfaces or generic neon-purple backdrops; re-grade toward natural micro-contrast and restrained accents.

What this rule catches

PNG pixel profile matches default AI-slop aesthetics: dominant neon purple-indigo-pink palette or hyper-saturated airbrushed plastic sheen.

Before and after examples

Original (flagged)
1024x1024 dark-mode hero PNG with 42% #0B0B14 dark backdrop and 28% glowing #7C3AED/#EC4899 purple-pink pixels
Fallback trap (still sounds like AI)
1024x1024 PNG pushing every surface to 92% saturation with airbrushed zero-texture gradients
Clean version
1024x1024 PNG on #F6F7F5 paper ground with crisp ink typography and <= 5% single vermilion accent

Edit note: Pixel heuristics are advisory signals; crisp UI screenshots on neutral grounds stay cleanly below thresholds.
