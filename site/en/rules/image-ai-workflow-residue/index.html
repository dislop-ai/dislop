Image AI workflow residue & provenance

image-ai-workflow-residue Slide Deck, Web UI & Graphic Layout (deck-and-ui) warning image Markdown card
HOW TO JUDGE

Strip accidental raw prompt/seed workflow JSON before shipping assets; keep legally required C2PA or IPTC trainedAlgorithmicMedia disclosures intact.

What this rule catches

Raster image embeds unstripped AI generation prompt/workflow parameters (warning) or explicit synthetic provenance tags (info — retain required legal disclosures).

Before and after examples

Original (flagged)
PNG tEXt chunk `parameters`: `masterpiece, neon glow\nNegative prompt: blurry\nSteps: 28, Sampler: Euler a, CFG scale: 7`
Fallback trap (still sounds like AI)
Stripping legal C2PA / `trainedAlgorithmicMedia` provenance tags instead of inspecting or re-shooting the asset
Clean version
Clean PNG/JPEG export with raw prompt/node-graph chunks removed and natural photographic or editorial raster assets

Edit note: Removing leaked ComfyUI/A1111 prompt strings protects internal workflows; never strip legally mandated AI disclosures.
