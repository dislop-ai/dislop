dislop / Rules / ui-dead-control

Dead placeholder link or button

ui-dead-control AI Delivery Artifacts (core) error html, jsx Markdown card
HOW TO JUDGE

Wire the control to a real destination, explain why it is disabled via title/aria-describedby, or remove the fake button.

What this rule catches

Placeholder href="#" link, empty button, or unexplained disabled button typical of generated UI mockups.

Before and after examples

Original (flagged)
<a href="#" class="btn">Download report</a>
Fallback trap (still sounds like AI)
<button disabled class="btn">Download AI-Powered Insights</button>
Clean version
<a href="./reports/q3-audit.pdf" class="btn">Download Q3 audit (PDF)</a>

Edit note: Point links to real targets and drop placeholder buttons that do nothing.

Run locally via CLI

npx --yes dislop explain ui-dead-control
npx --yes dislop check . --pack core
