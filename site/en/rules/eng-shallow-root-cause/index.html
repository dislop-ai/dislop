Stop-thinking 'human error' root cause

eng-shallow-root-cause Engineering RFC, PR & Postmortem (engineering-spec) warning markdown, text, docx Markdown card
HOW TO JUDGE

Ask why the tooling allowed a single manual action to cause an outage, and write that missing check as the root cause.

What this rule catches

Postmortem stops at 'human error' instead of identifying the missing system guardrail.
