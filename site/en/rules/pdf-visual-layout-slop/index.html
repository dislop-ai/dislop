PDF raster slides or flat typography

pdf-visual-layout-slop Slide Deck, Web UI & Graphic Layout (deck-and-ui) warning pdf Markdown card
HOW TO JUDGE

Export slides with selectable vector text, restore a >= 1.2x title-to-body type scale, keep body type >= 11pt, and vary layout structure across slides.

What this rule catches

PDF slide/poster layout exhibits synthetic template defects: multi-page raster-only slides, collapsed font hierarchy, crushed < 9.5pt body copy, or 4+ consecutive identical landscape slide skeletons.

Before and after examples

Original (flagged)
4-page landscape 960x540 PDF deck where every slide is a single rasterized PNG image with 0 selectable text operators
Fallback trap (still sounds like AI)
4-page landscape PDF deck shrinking all body text to 8.5pt with 10pt titles (1.17x ratio) to cram paragraphs
Clean version
5-page landscape PDF deck with 28pt assertion headlines, 13pt body copy, and alternating tables and charts

Edit note: Portrait prose reports and single-page portfolios are exempt from landscape slide density and monotony rules.
