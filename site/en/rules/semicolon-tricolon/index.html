dislop / Rules / semicolon-tricolon

Three-part balanced semicolon pitch

semicolon-tricolon Business Brief & Technical Proposal (business-brief) warning markdown, text, html, docx, pptx Markdown card
HOW TO JUDGE

Break the symmetry: split into plain sentences of unequal length or keep only the concrete behaviors.

What this rule catches

Three-part balanced semicolon pitch sentence reads like generated marketing cadence.

Before and after examples

Original (flagged)
The client validates forms on input; the worker isolates slow jobs in queues; the dashboard tracks every timeout live.
Fallback trap (still sounds like AI)
Validate early. Queue smart. Track live.
Clean version
The client validates fields on input, slow jobs run in a separate queue, and requests over 5s trigger an on-call alert.

Edit note: Two-clause contrasts, parenthetical citations, and legal obligations ('shall ...; must ...') stay clean.

Run locally via CLI

npx --yes dislop explain semicolon-tricolon
npx --yes dislop check . --pack business-brief
