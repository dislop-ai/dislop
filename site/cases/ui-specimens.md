# Non-Mainstream Design, Typography & Academic References

Verified on 2026-11-21. Policy: Indexes public homepage URLs, academic identifiers, and abstract design/writing extraction notes only. No scraping, mirroring, or copying of protected layouts or prose.

- [Verbalized Sampling: How to Mitigate Mode Collapse and Unlock LLM Diversity](https://arxiv.org/abs/2510.01171) (`academic-anti-convergence`, HTTP 200): Prompt models to verbalize a distribution of candidate outputs and probabilities to bypass RLHF typicality bias without retraining.
- [Artificial Hivemind: The Open-Ended Homogeneity of Language Models (and Beyond) (NeurIPS 2025 Best Paper)](https://arxiv.org/abs/2510.22954) (`academic-anti-convergence`, HTTP 200): Documents both intra-model repetition and inter-model homogeneity across INFINITY-CHAT; proves model-swapping alone does not ensure diversity.
- [Does Writing with Language Models Reduce Content Diversity? (ICLR 2024)](https://arxiv.org/abs/2309.05196) (`academic-anti-convergence`, HTTP 200): Shows feedback-tuned InstructGPT significantly reduces collective lexical and content diversity compared with unaided or base-model co-writing.
- [Generative AI enhances individual creativity but reduces the collective diversity of novel content (Science Advances 2024)](https://doi.org/10.1126/sciadv.adn5290) (`academic-anti-convergence`, HTTP 403): Empirical proof of the individual-polish versus collective-homogenization trade-off in AI-assisted ideation.
- [Turning Up the Heat: Min-p Sampling for Creative and Coherent LLM Outputs (ICLR 2025 Oral)](https://arxiv.org/abs/2407.01082) (`academic-anti-convergence`, HTTP 200): Dynamic probability truncation relative to top-token confidence; useful at token layer though insufficient alone for structural divergence.
- [Locally Typical Sampling (Meister et al., TACL 2023)](https://aclanthology.org/2023.tacl-1.7/) (`academic-anti-convergence`, HTTP 200): Selects tokens whose surprisal stays close to conditional entropy, balancing predictability against incoherent long-tail noise.
- [Rainbow Teaming: Open-Ended Generation of Diverse Adversarial Prompts (NeurIPS 2024)](https://arxiv.org/abs/2402.16822) (`academic-anti-convergence`, HTTP 200): Applies MAP-Elites quality-diversity grids to text generation, offering an architectural blueprint for orthogonal Generate-and-Select.
- [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (`ai-design-context`, HTTP 200): Popularized plain-text DESIGN.md tokens for coding agents; also serves as a cautionary baseline against copying a narrow set of tech brands.
